# Lavagem de Motores

Pequena app web para registar rapidamente os valores de uma lavagem de motores: PPM, temperatura e pH da amostra do tanque e de até 4 passagens por motor (Eng #1 e Eng #2).

## Como usar

- **Online:** abre a página do GitHub Pages deste repositório no browser.
- **Instalar no tablet ou telemóvel:** abre a página no Chrome, menu ⋮, "Adicionar ao ecrã principal". Depois da primeira abertura funciona sem internet.
- **Descarregar:** botão verde "Code", "Download ZIP".

## O que faz

- Calcula a diferença entre o PPM de cada passagem e o PPM do tanque. Abaixo de 150 ppm marca a lavagem do motor como concluída e põe as passagens seguintes em N/A.
- Copia o registo como texto ou no formato de tabela para colar no Excel.
- Guarda os registos no próprio aparelho. Mesma matrícula e mesmo dia gravam por cima do registo existente.

## Avisos

- Ferramenta pessoal de apoio ao registo. Não substitui o procedimento aprovado nem os registos oficiais de manutenção; confirma sempre os limites no procedimento em vigor.
- Os dados ficam só no browser do aparelho onde são introduzidos. Nada é enviado para a internet.
- A versão aparece ao lado do título da app.
